Discover to YNAB Converter

Upload a CSV file downloaded from Discover to convert it to YNAB format. The converted file will be automatically downloaded and ready for import into YNAB.

Upload the CSV file you downloaded from your Discover account. You can also drag and drop the file here.

How to use:

  1. Login to Discover
  2. Download your transactions from Discover's website as a CSV file
    Direct a CSV of the last 12 months (assuming Discover hasn't changed their URLs)
  3. Upload the file using the form above
  4. The converted file will download automatically
  5. Import the converted file into YNAB
